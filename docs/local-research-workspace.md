# 本地科研工作区 · 第二版

在项目目录启动已有环境：

```sh
.venv/bin/co-scientist serve --host 127.0.0.1 --port 7879
```

打开 `http://127.0.0.1:7879/`。浏览已有结果只读取本地数据；在创建研究窗口提交“开始研究”后，才会调用配置的模型与文献服务。

## 本版的变化

- **证据核查页**：按假设、范围提示、原文是否匹配筛选；查看关联论断、引用片段、原始链接及 Agent 标注的支持关系。
- **新颖性台账**：新假设保存检索式、结果数及失败/无结果状态。新颖性始终标记为“尚未核验”；检索无结果不能确认创新性。
- **网页轻量模式**：单并发、最多 6 条候选假设，每对最多比较 3 次（可通过 `ranking.lightweight_max_pair_matches` 配置）。小候选池达到成熟门槛后，先安排 Meta-review，再安排 Evolution。候选池与审查内容没有变化时，不反复调度同一轮演化。
- **研究对象**：创建研究时可指定 DNA、RNA，或自动识别/不限定。对象信息进入研究计划、提示词及证据核查。
- **报告的信息传递**：核查状态与范围限制进入后续 Agent 的输入；Meta-review 使用“被哪些假设引用”，避免把引用关系自动描述为支持关系。

## 核查状态的含义

“原文片段已匹配”表示：所引文字完整出现在该次工具返回的网页提取内容、数据库摘要或搜索摘要中。它不证明论文正确，也不证明该片段支持假设。卡片分别展示文字核对状态与 Agent 的科学判断。

DNA/RNA 范围提示基于已保存标题、引文及工具返回文本中的显式关键词，属于待核对提示。没有提示不能证明研究条件一致；物种、孔型、化学版本和 basecaller 仍需研究者检查。

旧试跑没有保存本版逐条核查元数据，因此保持“未核验”，不会被回填成已验证，也不会自动重新请求文献或改写历史报告。CLI 后端没有回传来源正文时，也保持未核验。

本版不包含自动公开数据分析、湿实验验证或课题组多人账号系统。标准 CLI 研究策略继续保留；网页轻量模式有独立的资源限制。

## 主要代码

- `co_scientist/safety/evidence.py`：离线来源收集、完整引文匹配、新颖性台账与核查摘要。
- `co_scientist/orchestrator/research_policy.py`：成对比较上限与小样本成熟门槛。
- `co_scientist/agents/supervisor.py::_decide_lightweight`：反馈、演化和比较的有界调度。
- `co_scientist/web/studio.py`：证据与策略数据接口。
- `co_scientist/web/static/studio.js`：证据页和创建研究流程。
